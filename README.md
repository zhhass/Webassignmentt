# Assignment #6. jQuery (Selectors, Effects, Animations)

**Student:** Tolegen Zhassulan · **Group:** SE-2526

A multi-page site that practises jQuery 3.7.1 (loaded from the official CDN). The navbar links every page.

| Page | Tasks | What it shows |
|---|---|---|
| `index.html` | 0–1 | `$(document).ready`, console message, ID/class/tag selectors, `.text()`, `.html()`, `.css()` |
| `effects.html` | 2–4 | `hide/show/toggle`, `fadeIn/fadeOut/fadeToggle`, `slideUp/slideDown/slideToggle` |
| `dom.html` | 5–7 | `append/prepend/remove`, `.attr()` for `src` and `href`, live form preview with `.val()` + `.text()` |
| `animations.html` | 8–10 | `.animate()`, chained (queued) animations, combined opacity + size + position |
| `project.html` | 11 | Mini project: Accordion Menu with slide animations |

## Run locally
Open `index.html` in a browser (internet needed for the CDN, fonts and sample photos).

## Deploy (GitHub Pages)
1. Push the files to a GitHub repository.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. Open `https://<username>.github.io/<repo>/`.

## Structure
`css/style.css` shared styles · `js/*.js` one script per page.
