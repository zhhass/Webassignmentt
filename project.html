Mini Project: Accordion Menu

Click a heading to open its section. Only one stays open at a time.

A JavaScript library that shortens DOM selection, events, effects and AJAX into a few readable calls.

They use the same syntax as CSS, so $("#id"), $(".class") and $("tag") are quick to learn.

.animate() changes numeric CSS properties over time, and calls chained on one element run in a queue.

It slides an element open if it is hidden and closed if it is visible.
